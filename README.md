# Курьер ПДД

Мобильная 2D-игра для подготовки к теории на права: все 800 вопросов экзаменационных билетов ПДД (категории A, B, M) превращаются в игровые ситуации в вымышленном городе.

Техническое задание, этапы и журнал работ — в [CLAUDE.md](CLAUDE.md).

**Игра:** https://artemigna777-sudo.github.io/Pdd.game/

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | Установить зависимости (один раз) |
| `npm run dev` | Запустить игру локально |
| `npm run import` | Заново извлечь вопросы и картинки из PDF в `data/raw/` и подключить пояснения |
| `npm run validate` | Проверить `data/questions.json` и вывести отчёт |
| `npm run mapping` | Разложить вопросы по главам и расставить точки на картах районов (из `data/scenes.json`) |
| `npm run coverage` | Проверить, что каждый вопрос размещён в игре ровно один раз |
| `npm test` | Автотесты: дорожный граф, расстановка точек, история билетов, прогресс и повторы ошибок, сюжет |
| `npm run test:e2e` | Браузерные тесты: управление касаниями, серии вопросов, мини-игры, история билетов, сюжет главы 1, разбор ошибок, финал |
| `E2E_FULL=1 npx playwright test chapter1-full` | Долгий браузерный тест: вся глава 1 от пролога до наград (около 10 минут) |
| `npm run build` | Проверить типы и собрать игру в `dist/` |
| `npm run icons` | Перерисовать иконки приложения |

## Где что лежит

| Путь | Содержимое |
|---|---|
| `data/raw/` | Исходный файл с билетами (PDF) |
| `data/raw/pdd_russia/` | Пояснения к ответам из открытого набора [pdd_russia](https://github.com/etspring/pdd_russia) |
| `data/questions.json` | Вопросы в формате из CLAUDE.md (создаётся `npm run import`) |
| `data/import-report.md` | Отчёт последнего импорта |
| `public/images/` | Картинки билетов, извлечены из PDF без изменений |
| `public/icons/` | Иконки приложения (создаются `npm run icons`) |
| `data/scenes.json` | Разобранная вручную по картинкам сцена каждого вопроса: шаблон или мини-игра и участники движения |
| `data/mapping.json` | Где в игре встречается каждый вопрос: глава, точка на карте района, шаблон, параметры (создаётся `npm run mapping`) |
| `scripts/` | Импорт, темы, проверка данных, размещение, покрытие, иконки |
| `src/world/` | Мир без графики: карты районов, главы, дорожный граф, шаблоны сцен, расстановка точек |
| `src/game/city/` | Город в Phaser: отрисовка карты, машина, управление, сцены у точек интереса |
| `src/game/interior/` | Мини-игры: автошкола, инспектор ДПС, автосервис, аптечка |
| `src/progress/` | Прогресс игрока: ответы, работа над ошибками (повторы через 1, 3 и 7 дней), опыт и уровни, главы, финал |
| `src/story/` | Сюжет: персонажи, пролог, истории десяти глав, финал |
| `src/ui/` | Интерфейс поверх игры: меню, город, сюжетные сцены, карточка вопроса, прогресс, разбор ошибок, финал, билеты, история попыток, настройки |
| `tests/` | Автотесты |
| `.github/workflows/deploy.yml` | Сборка и публикация на GitHub Pages при пуше в `main` |
