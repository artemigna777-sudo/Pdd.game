# Пояснения к ответам: pdd_russia

Файлы в `tickets/` скопированы без изменений из открытого репозитория
[etspring/pdd_russia](https://github.com/etspring/pdd_russia), папка `questions/A_B/tickets/`,
коммит `fa37933` от 2026-09-02.

Из них берётся только поле `answer_tip` (пояснение к ответу). Вопросы, варианты и правильные
ответы в игре по-прежнему берутся из PDF в `data/raw/`. Пояснение подключается к вопросу, только
если у вопроса в этом наборе тот же билет, тот же номер, то же число вариантов и тот же
правильный ответ, что и в PDF (проверяет `npm run import`).

Лицензия в репозитории не указана. В игре пояснения подписаны ссылкой на источник.

Как обновить: скачать свежие файлы из `questions/A_B/tickets/` того же репозитория в
`tickets/`, поправить коммит и дату выше, запустить `npm run import` и `npm run validate`.
