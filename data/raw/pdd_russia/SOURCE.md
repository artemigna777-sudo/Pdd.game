# Пояснения к ответам: pdd_russia

Файлы в `tickets/` скопированы без изменений из открытого репозитория
[etspring/pdd_russia](https://github.com/etspring/pdd_russia), папка `questions/A_B/tickets/`,
коммит `fa37933` от 2026-09-02.

Из них берётся только поле `answer_tip` (пояснение к ответу). Вопросы, варианты и правильные
ответы в игре по-прежнему берутся из PDF в `data/raw/`. Пояснение подключается к вопросу, только
если у вопроса в этом наборе тот же билет, тот же номер, то же число вариантов и тот же
правильный ответ, что и в PDF (проверяет `npm run import`).

Лицензия в репозитории не указана. В игре пояснения подписаны ссылкой на источник.

Как обновить: скачать свежие файлы из `questions/A_B/tickets/` того же репозитория в
`tickets/`, поправить коммит и дату выше, запустить `npm run import` и `npm run validate`.

# Дорожные знаки для Знакодекса: pdd_russia

`signs/signs.json` скопирован без изменений из того же репозитория (файл `signs/signs.json`,
тот же коммит `fa37933`). В `signs/images/` — без изменений те картинки из `images/signs/`,
которые нужны знакам из билетов.

`npm run signs` берёт отсюда название, картинку и описание знака для альбома (`data/signs.json`,
картинки — в `public/signs/`). Какие знаки есть в билетах — по разметке сцен `data/scenes.json`.
Из описаний убираются только штрафы (текст после «Наказание»), служебные сноски и лишние пробелы.

Особенности набора:
- у знаков 1.4.1–1.4.6 и 6.21.1–6.21.2 одна запись на все варианты (1.4 и 6.21);
- под номером 5.14 в наборе другой знак — «Конец полосы для велосипедистов» (по ПДД это 5.14.3),
  а знаков 5.14 «Полоса для маршрутных транспортных средств» и 5.14.2 «Полоса для велосипедистов»
  нет. Таблички 8.4.3 тоже нет. Эти знаки в альбом не попадают (список — в `data/signs.json`,
  поле `missing`);
- у 8.4.1 и 8.16 в наборе нет картинки: в альбоме вместо неё табличка с номером.

Как обновить: скачать свежий `signs/signs.json` и нужные картинки из `images/signs/`, поправить
коммит выше, запустить `npm run signs` (скрипт напишет, каких картинок не хватает).
