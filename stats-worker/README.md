# Посредник статистики (Cloudflare Worker)

Отдаёт статистику GoatCounter только автору игры. Ключ GoatCounter хранится у посредника, а не в игре.
Игра показывает статистику на секретном экране («Настройки» → 7 касаний по «Версия игры» → пароль автора).

- Адрес: https://kurier-pdd-stats.artemigna777.workers.dev (в игре — `STATS_PROXY` в `src/config.ts`).
- Код: `worker.js`. В Cloudflare его загружает GitHub (`.github/workflows/stats-worker.yml`, `wrangler deploy`
  с настройками из `wrangler.jsonc`) при каждом изменении папки `stats-worker` в `main`, а ещё вручную: Actions →
  «Посредник статистики на Cloudflare» → Run workflow. Вставить код через редактор Cloudflare на iPhone не
  получается: в нём нет кнопки «Вставить».
- Для загрузки нужен секрет репозитория `CLOUDFLARE_API_TOKEN` (GitHub → Settings → Secrets and variables →
  Actions). Создаётся так: Cloudflare → профиль → **API Tokens** → **Create Token** → шаблон
  **Edit Cloudflare Workers**. Если у ключа доступ к нескольким аккаунтам — ещё `CLOUDFLARE_ACCOUNT_ID`.
- Секреты: kurier-pdd-stats → **Settings** → **Variables and Secrets** → **Add**, тип **Secret**.
  - `GC_TOKEN` — ключ API GoatCounter с правом «Read statistics». Создать его можно так: на сайте счётчика
    коснуться своего имени вверху → **API**.
  - `STATS_KEY` — ключ автора, 64 знака: только цифры и буквы a–f, без слов вроде «STATS_KEY —». Он получается
    из пароля автора (`authorKey` в `src/stats/author.ts`) и есть только у Артёма. Пробелы по краям не мешают,
    а если в значении есть лишнее, проверка адреса посредника скажет «STATS_KEY задан неверно».
- Проверка: открыть адрес посредника в браузере. Должно быть «Курьер ПДД: посредник статистики работает.».

Что посредник умеет:

- отвечает только на запросы с ключом автора (`Authorization: Bearer <STATS_KEY>`);
- читает только статистику: `/api/v0/stats/total`, `hits`, `toprefs`, `systems`, `locations` и т. п.;
- отдаёт экрану статистики весь отчёт одним маленьким ответом (`GET /api/report`): сам спрашивает GoatCounter,
  повторяет запрос, если тот ответил «слишком часто» (429), и возвращает только числа — несколько килобайт;
- отвечает браузеру только со страниц игры (CORS);
- передаёт итог дуэли автору вызова (этап 14): `PUT /duel/<номер>` — друг оставляет свой результат,
  `GET /duel/<номер>` — игра автора его забирает. Ключ автора для этого не нужен. Хранится только имя, ответы и
  время ответившего, 30 дней, и только первый ответ на вызов;
- держит комнаты дуэли в реальном времени (этап 16): `/live/<код>` — WebSocket только со страниц игры.
  Комната — Durable Object `LiveRoom` (привязка `LIVE`, правила — `room.js`): двое игроков, задания от создателя,
  ответы пересылаются сопернику. Верных ответов посредник не знает и после ухода обоих ничего не хранит;
- держит общую таблицу лидеров по опыту и заработанным монетам: `PUT /player` — игра присылает о себе,
  `GET /board?by=xp|coins&id=…` — первые 20 и своё место. Ключ автора не нужен, только страницы игры.
  Игроки — Durable Object `Players` с SQLite (привязка `PLAYERS`, правила и SQL — `players.js`). Хранится
  случайный номер игры, имя, опыт и монеты — только у тех, кто сам вступил в таблицу (имя с матом не
  принимается), и готовность к экзамену в процентах — у тех, кто не выключил анонимную статистику. Кто не
  заходил год, удаляется. Готовность видна только автору — в отчёте `/api/report` как число игроков в каждом
  десятке процентов (0–10%, 10–20%, … 90–100%) за 7 и 30 дней.

Итоги дуэлей лежат в хранилище Workers KV `kurier-pdd-duels` (привязка `DUELS`). Его создаёт и подключает сама
загрузка через GitHub (`kv-config.mjs`), ничего делать руками не нужно: шаблон ключа «Edit Cloudflare Workers»
даёт и право на Workers KV. Если хранилище создать не получилось, загрузка напишет предупреждение, посредник
заработает без итогов дуэлей, а игра будет показывать итог по ссылке-ответу, как раньше.

Комнаты (`LIVE`) и игроков (`PLAYERS`) загрузка тоже подключает сама. Если Cloudflare их не примет, загрузка
напишет предупреждение и загрузит посредника без них: статистика и дуэли по ссылке работают, а живая дуэль
и таблица лидеров скажут, что связи нет.

Тесты — `tests/worker.test.ts`, `tests/duelSync.test.ts`, `tests/live.test.ts`, `tests/players.test.ts`
и `tests/board.test.ts`.

Если пароль автора сменить, нужно заменить и `STATS_KEY`.
