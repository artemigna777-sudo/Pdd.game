# Реклама для TikTok «Не можешь сдать теорию?»

Вертикальный ролик 1080×1920, 28,5 секунды. Сделан по образцу ролика, который прислал Артём:
тот же монтаж в те же доли секунды и та же музыка, но свой сюжет.

1. Диалог двух человечков: один дважды завалил теорию, другой сдал с первого раза — «просто играл».
2. «Демо»: телефон, 800 вопросов ПДД, машинка курьера проезжает значки — все с галочкой.
3. История в стиле старой гравюры: первый лётный тренажёр Эдвина Линка (США, 1929) — пилоты учились
   летать, не отрываясь от земли. «Сегодня так учат ПДД» — гравюра оживает в настоящую игру.
4. «Зубрёжка / Игра», «Хватит зубрить — начни играть», «Ссылка в био».

Вся графика нарисована кодом (`build.ts`), город — настоящий кадр игры (`shot.ts`), в телефоне —
запись игры из трейлера. Факт про тренажёр: Wikipedia, «Link Trainer».

## Как пересобрать

Нужны Node.js 22, ffmpeg и ffprobe в `PATH`.

1. Музыка — из присланного ролика, первые 28,5 секунды (дальше у него заставка TikTok). В репозиторий
   её не кладём: права на трек не наши.
   ```
   ffmpeg -i <ролик-образец>.mp4 -t 28.5 -vn -af "afade=t=out:st=28.15:d=0.35" -ar 44100 -ac 2 trailer/ad/video/music.wav
   ```
2. Запись игры: `cp trailer/video/clips/drive.mp4 trailer/ad/video/` (запись — `npx tsx trailer/record.ts drive`).
3. Кадр города: запустить игру (`npx vite --port 5173 --strictPort`) и `npx tsx trailer/ad/shot.ts`.
4. Композиция: `npx tsx trailer/ad/build.ts` → `trailer/ad/video/index.html`. Тексты и моменты склеек — в начале `build.ts`.
5. Рендер:
   ```
   cd trailer/ad/video
   npx hyperframes@0.8.119 render . --fps 30 --crf 20 --video-frame-format png -o ../kurier-pdd-ad.mp4
   ```

Для TikTok удобнее загрузить ролик без звука (`ffmpeg -i kurier-pdd-ad.mp4 -c:v copy -an kurier-pdd-ad-bez-zvuka.mp4`)
и добавить тот же звук прямо в TikTok: так с правами на музыку проблем не будет.
