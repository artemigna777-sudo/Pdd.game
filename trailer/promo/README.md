# Видео для страницы приложения в RuStore

Два ролика для VK Видео (RuStore берёт видео только оттуда):

- `kurier-pdd-rustore.mp4` — ролик для поля «Видео»: вертикальный 1080×1920, 60 кадров в секунду, 46 с,
  со звуком. Настоящие кадры игры в телефоне, рисованные кадры сюжета, кинетический текст, музыка в такт.
- `kurier-pdd-background.mp4` — фоновое видео карточки: горизонтальное 1920×1080, 30 с, без звука,
  бесшовная петля — город сверху, машина курьера в потоке. Без текста: RuStore закрывает нижнюю треть
  карточкой приложения.

Всё нарисовано и сыграно кодом игры; музыка синтезирована кодом (`music.ts`), шрифт — Montserrat (SIL OFL).

## Как пересобрать

Нужны Node.js 22 и ffmpeg.

1. Запустить игру: `npx vite --port 5173 --strictPort`.
2. Записать кадры игры: `npx tsx trailer/promo/record.ts` (можно выборочно: `… record.ts film exam`).
   Запись покадровая (`frames.ts`): время страницы остановлено, каждый кадр — 1/30 с игрового
   времени и снимок экрана в пикселях 2×. Поэтому запись ровная, даже когда браузер без видеокарты
   рисует город медленнее реального времени. Город — около 1 секунды на кадр, всё вместе — около 40 минут.
3. Музыка: `npx tsx trailer/promo/music.ts`.
4. Композиция: `npx tsx trailer/promo/build.ts` → `trailer/promo/video/index.html`.
5. Рендер ролика:
   ```
   cd trailer/promo/video
   npx hyperframes@0.8.119 render . --fps 60 --quality delivery --video-frame-format png -o ../kurier-pdd-rustore.mp4
   ```
6. Фоновое видео: `bash trailer/promo/background.sh`.

Время сцен и звуков — `timeline.ts`, отрезки записей — `SHOTS` в `build.ts`.
