# Ролик-история «Третья попытка» (TikTok, 51,6 с)

По образцу Артёма: мультяшная история с героем в той же рисовке (плоские цвета, тёмный контур «от руки»,
тёплый и холодный свет, зерно), без подписей — историю рассказывают кадры. Игру не рекламируем: она мелькает
у героя в телефоне (автобус, вечер, карта района), в конце — «Решение в био», без строки поиска TikTok.

Сюжет: «Экзамен не сдан» → дождь у ГИБДД → уснул на билетах → пересдача обведена в календаре → снова
«не сдан» → слёзы ночью → (музыка взрывается) утро, шторы → в автобусе проходит перекрёсток в телефоне — и
видит ту же зебру в жизни → вечером на кровати, распечатки билетов в мусорке → папа за завтраком косится →
в машине сын первым замечает «Главную дорогу» → дни в календаре → зеркало → солнечная ГИБДД → вопросы 1…20 →
«Экзамен сдан» → радость, папа обнимает → едут домой на закате → город сверху, как карта в игре.

- `art.ts` — рисовка: герой (лица с 11 выражениями), папа, худи и свитер, телефон с экраном игры, монитор
  экзамена, ГИБДД, календарь, машины, знаки, светофор.
- `shots.ts` — 26 кадров: что в кадре, камера, свет, анимации. Склейки `CUTS`: тихая часть — как у образца,
  после 14,13 с — по долям музыки (0,7085 с).
- `build.ts` — композиция HyperFrames в `out/`.

## Как пересобрать

Нужны Node.js 22, ffmpeg и ffprobe в `PATH`.

1. Музыка — из образца, без изменений, обрезана и затухает в конце (в репозиторий не кладём, права не наши):
   `ffmpeg -i образец-история.mp4 -t 51.583 -vn -af "afade=t=out:st=50.2:d=1.38" -ar 44100 -ac 2 trailer/story/music/story.wav`
2. Проверка кадров: `npx tsx trailer/story/build.ts`, затем `npx hyperframes snapshot trailer/story/out --at 1,7,15`.
3. Рендер: `sh trailer/story/render.sh` → `trailer/story/mp4/kurier-pdd-istoriya.mp4` и копия без звука.
